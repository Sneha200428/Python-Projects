# Library Management System

A command-line Library Management System built using Python and Object-Oriented Programming (OOP).

## About the Project

This project is designed to manage books, library members, and book borrowing activities. It uses OOP principles to organise code into separate classes and make the program easier to maintain.

## Planned Features

- Add and remove books
- View all books
- Search for books
- Register library members
- Issue books to members
- Return books
- Track book availability
- Save and load data using JSON

## Concepts Used

- Classes and Objects
- Constructors and Instance Methods
- Encapsulation
- Inheritance
- Polymorphism
- Abstraction
- Composition
- JSON File Handling

## Technologies Used

- Python
- JSON
- Git and GitHub
